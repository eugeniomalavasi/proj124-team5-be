# Description

This is the back-end of the final project for the 6 month course of Full Stack Web Developer made with Boolean, the concept of the site is like AirBNB, so we created our db and then filled it with a seeder, made the dashboard of a user in which can make all the CRUD, sponsor an apartment with full working payment system made with Braintree API, we made our own API to recall it on the front end, and we also implemented stats for each apartment, in the landing page.
